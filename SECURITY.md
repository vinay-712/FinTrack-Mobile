# Security Policy

## Supported versions

FinTrack Mobile is currently a design prototype. Security updates apply to the latest version on the `main` branch.

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in a public issue.

Report security concerns privately to the repository owner through their GitHub profile. Include:

- A clear description of the issue
- Steps to reproduce it
- The affected file or behavior
- Potential impact
- A suggested mitigation, if available

You can expect acknowledgement as soon as practical. Confirmed issues will be prioritized based on impact and documented after a fix is available.

## Prototype limitations

The current prototype uses demonstration data and does not connect to financial institutions, transmit financial records, or store credentials. Production use would require a dedicated security review, authenticated APIs, encrypted storage, dependency monitoring, and privacy controls.
