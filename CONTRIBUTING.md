# Contributing to FinTrack Mobile

Thanks for your interest in improving FinTrack Mobile. Contributions that strengthen usability, accessibility, visual consistency, and code quality are welcome.

## Before you begin

1. Review the [README](README.md) and the linked Figma design.
2. Search existing issues before opening a new one.
3. Keep proposals focused on one clear improvement.
4. For visual changes, explain how the change supports the existing design principles.

## Development

This prototype has no dependencies or build step.

```bash
git clone https://github.com/vinay-712/FinTrack-Mobile.git
cd FinTrack-Mobile
```

Open `index.html` in a modern browser.

## Pull requests

A strong pull request should:

- Have a concise, descriptive title
- Explain what changed and why
- Include screenshots for visual changes
- Preserve responsive behavior across mobile and desktop
- Maintain keyboard and screen-reader usability
- Avoid unrelated formatting or refactoring

## Commit style

Use short, intentional commit messages:

```text
feat: add transaction filter
fix: improve mobile overflow behavior
docs: clarify prototype setup
style: refine budget card spacing
```

## Design quality checklist

- [ ] Matches the established FinTrack visual language
- [ ] Works at 390 px mobile width
- [ ] Remains presentable on large desktop screens
- [ ] Uses existing colors and spacing patterns
- [ ] Maintains readable contrast
- [ ] Includes clear focus and hover states for interactive elements
- [ ] Does not rely on color alone to communicate status

## Reporting issues

Include:

- A clear summary
- Steps to reproduce
- Expected and actual behavior
- Browser and device information
- Screenshots or recordings when helpful
